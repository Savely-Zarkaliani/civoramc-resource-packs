# CivoraMC resource packs

Public client resource packs only. No plugin source, server configuration, database, player data or credentials are stored here.

The current package and its checksums are listed in `manifest.json`. Server download links are pinned to a full commit SHA, not a mutable branch. Included third-party license notices remain inside the ZIP.

Ferry v4 (`civoramc-ferry-v4.manifest.json`) preserves every v3 entry and adds a fully transparent vanilla bamboo raft entity texture for short native seat carriers. Regular bamboo rafts are reserved for this server feature; chest rafts and all wooden boat variants remain unchanged. No new shader override is added. Native seat tests do not replace visual acceptance in Minecraft, including Iris/Photon.
